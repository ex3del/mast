# A-20 Ревьюер `mast merge` видит правила проекта

**Мои пути:** hooks/**, plugins/*/**, tests/**, .claude/rules/review.md
**Не трогаю:** всё остальное; README и CHANGELOG — строками про ревью
**Готово когда:** на живых фикстурах, по 3 прогона: правка кода нарушает правило из `.claude/rules/` с совпавшими `paths:` — не `ок` 3 из 3; нарушает инвариант из проектного `CLAUDE.md` — не `ок` 3 из 3; нарушает правило глобального `CLAUDE.md` — не `ок` 3 из 3; прежние 9 прогонов A-15 — верный вердикт 9 из 9; решение человека из строки пункта — ревьюер не выносит его вопросом, не `не уверен` 3 из 3; заявленный в «готов» замер без проверяющего его теста в диффе — не `ок` 3 из 3; правило, чьи `paths:` не задевают дифф, ревьюеру не передаётся — 0 лишних; цена ревью на фикстуре — замерена (было: медиана 5 008 токенов).

**Goal:** ревьюер `mast merge` судит дифф по правилам проекта и по заданию пункта, а заявления
автора сверяет с диффом.

**Architecture:** `verdict()` в `hooks/mast.py` собирает из дерева вершины ветки проектный
`CLAUDE.md` (`./CLAUDE.md`, `./.claude/CLAUDE.md`) и `.claude/rules/**/*.md` — без `paths:` и с
`paths:`, задевающими файлы диффа, — плюс глобальный `CLAUDE.md` из `CLAUDE_CONFIG_DIR` или
`~/.claude`; строку пункта целиком из `ROADMAP.md` и сообщение последнего коммита ветки («готов»).
`review.ask()` кладёт их во вход отдельными блоками, промпт `review.md` велит: правила обязательны,
решения человека из строки не выносить вопросом, заявления «готов» сверять с диффом.

**Tech Stack:** Python 3 stdlib, pytest, Claude Code (`claude -p --safe-mode`).

**Spec:** строка A-20 в `ROADMAP.md` (в `main` с `331716a`).

## Проблемы

- `HOME` или `CLAUDE_CONFIG_DIR` во временном каталоге — `claude -p` теряет вход по подписке
  (`terminal_reason: api_error`). Глобальный `CLAUDE.md` в живом замере подставляется в
  `mast.CLAUDE_HOME`, `mast` зовётся в процессе теста.

## Принятые решения

- «Проектный `CLAUDE.md`» — `./CLAUDE.md` и `./.claude/CLAUDE.md`, как их грузит площадка. Без
  `CLAUDE.local.md`, `CLAUDE.md` родителей и подкаталогов, `AGENTS.md`, `~/.claude/rules/`:
  решение человека называет три источника, шире не расширяем.
- Память ревьюера — из дерева вершины ветки, а не из рабочего каталога основной копии: это то,
  что окажется в `main` после вливания, и незакоммиченное в основной копии не влияет на вердикт.
