# A-15 Ревью с чистым контекстом перед вливанием

**Мои пути:** hooks/**, plugins/*/**, tests/**
**Не трогаю:** всё остальное; README и CHANGELOG — минимально, строками про ревью
**Готово когда:** на фикстурах, по 3 прогона: заведомо плохая правка rules — не `ок` 3 из 3; чистая правка — `ок` 3 из 3; правка кода, нарушающая «Готово когда», — `отказ` 3 из 3; `mast merge` без вердикта не вливает — 1 из 1; `решил человек` при совпавшем отпечатке — вливает без вызова ревьюера 1 из 1; дифф изменился после вопроса или `ждёт человека` не от ревью — не вливает без нового ревью 2 из 2; цена одного ревью в токенах — замерена и записана в коммит.

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Шаги — чекбоксы `- [ ]`.

**Goal:** `mast merge` не вливает ветку без вердикта ревьюера с чистым контекстом.

**Architecture:** `hooks/review.py` зовёт `claude -p` в безопасном режиме без инструментов,
вход — дифф без `docs/roadmap/` и критерий, выход — JSON по схеме. `close()` в `hooks/mast.py`
зовёт ревью после линта и до `git merge`: `ok` — вливание, `refuse` — отказ с причинами,
`unsure` — слот `ждёт человека` коммитом с вопросом и отпечатком диффа (`git patch-id`).
Ответ человека `решил человек: …` при том же отпечатке вливает без ревьюера.
Промпт — `plugins/<язык>/locales/<язык>/review.md`.

**Tech Stack:** Python 3 stdlib, pytest, Claude Code ≥ 2.1.242 (`--safe-mode`, `--json-schema`).

**Spec:** строка A-15 в `ROADMAP.md` (в `main` с `3a8762f`) и «Принятые решения» ниже.

## Global Constraints

- Вход ревьюера — только дифф и «Готово когда»; без тем и тел коммитов, без `docs/roadmap/**`.
- Без вердикта (нет `claude`, таймаут, `is_error`, нет `structured_output`) — отказ, ничего не изменено.
- Флагов нет: ни пропуска ревью, ни вливания вопреки ему. Планка строже, если дифф трогает `.claude/**`, `**/CLAUDE.md`, `**/skills/**`.
- Тексты — в обоих языках, дерево заголовков `review.md` одинаковое; код правится в `hooks/`, копии — `tools/sync_plugins.py`.
- Файл кода ≤ 1000 строк; бамп версии 3.3.10 → 3.3.11 в обоих `plugin.json`.

## Review Focus

- `STATUS.md` пункта в диффе ветки — история пункта, до ревьюера доходить не должна.
- Ответ `claude` с `is_error`, без `structured_output`, с вердиктом вне схемы, пустой — «без вердикта».
- Вопрос ревьюера с переводом строки — слот одной строкой, линт без новых ошибок.
- Повторный `не уверен` при стоящем слоте или устаревшем ответе — слот один, ответ снят.
- Файл без расширения (`bin/mast`) — не «правило агента»: `segments()` считает его каталогом.

## Проблемы

## Принятые решения

- Ревьюер — `claude -p --safe-mode --tools "" --no-session-persistence --output-format json
  --json-schema … --model opus`, промпт через stdin. `--safe-mode` выключает CLAUDE.md,
  плагины, хуки, MCP, но не вход по подписке; `--bare` читает только `ANTHROPIC_API_KEY` —
  у OAuth-пользователей не работает. Пробный вызов: 2481 токен на входе — чужого контекста нет.
  Минимум Claude Code не растёт: `--safe-mode` с 2.1.169, `--json-schema` исправлен в 2.1.205,
  минимум плагина 2.1.242.
- Вход ревьюера — `git diff base tip` без `docs/roadmap/` и «Готово когда»; ни тем, ни тел
  коммитов, ни `STATUS.md`: там замеры и история пункта.
- Ответ человека на «не уверен» (решение человека 24.09 через диспетчера): `--force` и повторное
  ревью отвергнуты — забытый флаг держится на памяти диспетчера. Ответ — слот
  `решил человек: <ответ>` вместо `ждёт человека`, только для «вливай». Ревьюер не зовётся,
  только если последний коммит слота ревью этого пункта несёт тот же отпечаток диффа
  (`git patch-id --stable`, rebase его не меняет): так ответ на вопрос не от ревью или на
  прежний дифф не вливает ветку без ревью.
