# Детерминированные контракты вместо md-машинерии — ресёрч

23.09.2026. Повод — фидбек коллеги: «машинерия на md-файлах — слишком опасно; агенты кладут на
эти файлы; работает, работает, потом дрейф контекста — и всё». Связан с
[разгрузкой диспетчера](2026-09-23-dispatcher-load.md): там замерены нарушения, здесь — чем их закрыть.

**Происхождение фактов.** Проверено здесь: arXiv 2605.10039 (аннотация: 1650 сессий Claude Code
CLI, BF10 0,05–0,10, OR 0,944), `session_title` в коде Claude Code 2.1.280, цитаты из
документации Claude Code. Остальное — по отчёту агента-ресёрчера, ссылки внутри; числа по
Codex, накладные хуков (10 мс) и поведение fail-open перепроверить при взятии в работу.

## Главное

Коллега прав насчёт **процедур**, но не насчёт **данных**. `ROADMAP.md` агенты читают нормально,
а `roadmap_lint.parse()` уже задаёт ему грамматику — это фактически структурированный файл.
Дрейфует процедура: вливание, запуск, «кто что правит» — проза в скиллах, которую модель каждый
раз исполняет по памяти. Все замеренные нарушения — оттуда:

| Нарушение (транскрипты) | Правило-проза |
|---|---|
| `ROADMAP.md` переписан Python-вставкой через Bash | «правь Edit, не `sed`» |
| 16 из 17 ожиданий > 5 мин — модальный `AskUserQuestion` | «пока ждёшь ответа, пункт продолжает работу» |
| запуск пункта — ad hoc Python на 3,4k символов | «Запуск пункта», 1458 символов |
| проектные указания в `STATUS.md` от диспетчера | «план пишет сессия пункта» |
| 21% вызовов — правки кода/README (mast), 17% — `docker`/`ssh` (reinhold) | «роль диспетчера — вливание и связь» |

Внешние замеры о том же:

- **Структура файла инструкций не влияет, влияет длина сессии.** 1650 сессий Claude Code:
  размер, позиция, противоречия в файле инструкций — эффекта нет (BF10 0,05–0,10); соблюдение
  падает на 5,6% шансов с каждой следующей функцией (OR 0,944).
  [arXiv 2605.10039](https://arxiv.org/abs/2605.10039). Значит, переписыванием md дрейф не лечится.
- **Скилл не вызывается в 56% случаев** (Vercel): базовый уровень 53%, со скиллами 53%, с явной
  инструкцией 79%, с индексом в `AGENTS.md` 100%.
  [блог](https://vercel.com/blog/agents-md-outperforms-skills-in-our-agent-evals). Ровно наша
  схема «процедура живёт в скилле диспетчера».
- **Инструкций больше — соблюдение ниже:** Opus 4 при 100/250/500 инструкциях — 94,6/67,9/44,6%.
  [arXiv 2507.11538](https://arxiv.org/abs/2507.11538)
- **Сама Anthropic:** CLAUDE.md — «context, not enforced configuration. To block an action… use a
  PreToolUse hook». [memory](https://code.claude.com/docs/en/memory)

Контролируемого замера «хуки лечат дрейф» не нашлось ни у кого — это надо будет мерить самим.

## Как другие переводят процедуру в код

- **Gas Town:** `gt done` — один глагол со всеми побочными эффектами завершения
  ([design](https://github.com/steveyegge/gastown/blob/main/docs/design/polecat-self-managed-completion.md));
  `gt prime` на SessionStart/PreCompact; координатору PreToolUse запрещает Edit/Write. Но правила
  исполнителя остались прозой, а автокоррекция поверх дрейфа дала «spawn storms (6–7 polecats
  assigned the same bead)».
- **beads:** атомарный `bd update --claim`; `bd prime` — «to prevent agents from forgetting bd
  workflow after context compaction». Даже через CLI остаются гонки — отсюда предложение CAS.
- **Anthropic harness:** JSON-список фич, агент меняет только поле `passes`: «the model is less
  likely to inappropriately change or overwrite JSON files compared to Markdown files». Сам
  запрет — промптом.
- **Taskmaster:** MCP-инструменты, 7 штук ≈ 5k токенов в каждой сессии; «Never manually edit
  tasks.json» — проза без enforcement.
- **Kiro** делит хуки на `command` (детерминированный) и `agent` (промпт). **Spec Kit** — скрипты
  создают каталоги и валят проверку через exit 1, но его «hooks» — проза для агента.

## Ограничения площадки (важно для любого варианта)

- **Хуки fail-open.** exit 1, таймаут, незапустившийся хук (127) не блокируют — гейт «silently
  disabled». Урок A-7: проверять на настоящей установке.
- **Blocklist по командам обходится:** 22 regex обошли через `perl -i`, issue закрыт «not
  planned» ([#40408](https://github.com/anthropics/claude-code/issues/40408)). Стена — проверка
  **состояния** (что изменилось в файле, что уходит в коммит), а не перехват команды.
- Плагин не может поставлять permissions; `bin/` плагина попадает в PATH Bash-инструмента.
- `ask` в хуке модальный — стопорит очередь как `AskUserQuestion`; в `--bg` отвечать некому;
  в Codex `ask` считается упавшим хуком, и вызов **проходит**. Поэтому везде `deny` с причиной.
- **Codex (риск для A-10):** правки через `apply_patch` — путь файла в `tool_input.command`, а не
  `file_path`; хуки надо доверить через `/hooks`; `additionalContextLimit` ≈ 2500 токенов — ядро
  на 8200 символов, скорее всего, не влезет. Не проверено живьём.

## Инвентаризация: что становится полом

| Правило | Сейчас | Механизм |
|---|---|---|
| формат строки, «Готово когда» с числом | линт на Edit/Write | + линт после Bash, если `git diff --quiet` по файлам роадмапа ≠ 0 (10 мс); + перед `git commit` |
| «правь Edit, не `sed`» | проза | исчезает — закрыто строкой выше |
| роадмап и архив правит только основная копия | проза | `mast merge` отказывает, если ветка задела `ROADMAP.md`/`DONE.md`/`TECH_DEBT.md`; deny Edit/Write по cwd в `.claude/worktrees/` |
| номер — следующий свободный по двум файлам | grep | `mast add` на существующем `ledger_ids()` |
| запуск: строка → коммит → push → `claude --bg` | проза | `mast start X-N` собирает промпт сам, свободный хвост ≤ N символов |
| пересечение `Мои пути`, `sonnet` на opus-зоне, `fable` у `sonnet` | проза | отказы в `mast start`, `--force "причина"` в коммит |
| вливание: ff-only, диапазон, чистота, тезис, строка, долг, уборка | проза, 3503 символа | `mast merge X-N`; deny `git merge` в основной копии с причиной «зови `mast merge`» |
| тезис в `DONE.md` и удаление строки — одна правка | порядок прозой, долг в `TECH_DEBT.md` | атомарно в `mast merge`/`mast drop` — **закрывает долг** |
| последний коммит несёт критерий и было → стало | проза | отказ `mast merge`; проверяется форма, не правдивость цифр |
| перед «готово»: rebase, весь набор тестов, чистый статус | проза | `mast ready`; команду тестов проект объявляет в `dispatch.md` |
| сверка брошенных пунктов | проза + jq | `mast status`: сверка + inbox + «ждёт человека» |
| «Готово когда» меняет только человек | проза | PreToolUse на Edit `ROADMAP.md`: критерий существующего пункта изменился → deny «впиши `ждёт человека:`» |
| планы не в `docs/superpowers/**` | проза в ядре | deny Write туда, в причине — правильный путь |
| диспетчер спрашивает текстом; не правит код; не ходит в прод | проза, нарушено | deny по роли — см. ниже |

**Остаётся прозой (потолок):** когда спрашивать человека, три вопроса о модели, порог «находка →
пункт», планка ADR, «где ещё та же причина», митигейт, план → код, TDAID, куда писать (rules /
memory / CLAUDE.md), признаки `STATUS.md`, перезапуск по размеру контекста, предупреждение
соседней сессии перед коммитом (хуком — дорого и хрупко).

**Сигнал роли.** `session_title` есть во входе `SessionStart` и `UserPromptSubmit` — проверено по
коду установленного Claude Code 2.1.280 (`session_title: optional`), но **в документации хуков
его нет**: недокументированное поле может исчезнуть. `session_id` приходит во вход любого хука.
SessionStart пишет `${CLAUDE_PLUGIN_DATA}/<session_id>.role`, PreToolUse читает. Запасной путь —
`MAST_ROLE=dispatcher claude`. Не проверено: заполнено ли поле у `--bg`-сессий и есть ли оно в Codex.

## Рекомендация — пять шагов по порядку

Числа — черновики; по инварианту проекта «до» снимается замером скриптом по транскриптам.

1. **Линт по состоянию после Bash и перед `git commit`.** Правка критерия без числа через
   `sed -i`, `python3 -c`, `perl -i` → код 2, 3 из 3; коммит с новым нарушением → отказ 1 из 1;
   накладные на Bash без правки роадмапа ≤ 20 мс.
2. **`mast merge` + `mast drop` + deny `git merge` в основной копии.** Отказы на не-ff, грязный
   диапазон, ветку, задевшую файлы роадмапа, коммит без блока «Готово когда» — 4 из 4; вливание
   — 1 вызов инструмента; линт после вливания — 0 жалоб, долг о промежуточном состоянии закрыт;
   раздел «Вливание» ≤ 900 символов (сейчас 3503).
3. **`mast start` + `mast status`, `bin/mast`.** Отказы на неготовый пункт, пересечение путей без
   `--force`, `sonnet` на opus-зоне, `fable` у `sonnet` — 4 из 4; хвост промпта старта ≤ 300
   символов (медиана сейчас 1165).
4. **Guards по cwd worktree + Stop на последний коммит + deny `docs/superpowers/**`.** 4 сценария
   отказа — 4 из 4; прогон всех Edit/Write/Bash сессий пунктов из транскриптов reinhold через
   guard — ≤ 1% ложных отказов; каждый хук: `try/except` → причина → exit 2, тест проверяет, что
   каждый путь хука запускается (против fail-open).
5. **Роль диспетчера — после живой проверки `session_title` на `--bg`.** Ожиданий > 5 мин из-за
   модального вопроса: 16 → 0; правок кода из `*-dispatch` — 0; на «что от меня надо» отвечает
   `mast status`, диспетчер читает 0 файлов.

Для Codex и для ручной правки переносимый пол — pre-commit и CI **в проекте пользователя**. Это
его файлы — только через `/init-project` с диффом и вопросом.

## Где детерминизм вредит

- **Человек в редакторе** хуков не видит. `mast` обязан разбирать файл, поправленный руками, и
  на неразборчивый — громко отказывать, а не требовать монополии на файл.
- **Скрипты окостеневают на краевых случаях** (два захода вливания, часть работы в основной
  копии). Реакция — отказ и человек, не угадывание.
- **Stop-хук** не отличает «готово» от «пауза», тратит токены на блоки, площадка сдаётся после 8
  блоков подряд.
- **Форма ≠ правда:** «было → стало» в коммите не ловит выдуманные цифры.
- **Пересечение `Мои пути` грубое:** уже сейчас запретило бы A-10 и B-1 идти параллельно.
