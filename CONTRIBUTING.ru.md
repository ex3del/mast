# Участие в MAST

*English: [CONTRIBUTING.md](CONTRIBUTING.md)*

Спасибо за помощь. Баги и идеи — в [issues](https://github.com/ex3del/mast/issues), код — через
pull request в `main`. Писать можно по-русски.

## Подготовка

```bash
git clone https://github.com/<вы>/mast && cd mast
git config core.hooksPath .githooks     # pre-commit, который сторожит бамп версии
pytest                                  # весь набор должен быть зелёным
```

Попробовать свои правки в Claude Code без публикации: `claude --plugin-dir plugins/ru`
(или `plugins/en`).

## Неочевидные правила

- **Правьте источники в корне — `hooks/` и `locales/<язык>/`.** В каждом плагине
  `plugins/<язык>/` лежат их копии: маркетплейс ставит только каталог самого плагина.
  Копии обновляются командой `python3 tools/sync_plugins.py`; отставшую копию не пропустят
  ни pre-commit, ни CI.
- **Оба языка — вместе.** Правка текста в `locales/ru/` требует той же правки в
  `locales/en/`: сторожа сверяют состав файлов и дерево заголовков. Не пишете на одном из
  языков — скажите об этом в PR, перевод доделаем.
- **Правка метода поднимает версию** в обоих `plugins/*/.claude-plugin/plugin.json` (они
  должны совпадать). Без бампа Claude Code не доставит обновление никому. Правки только
  `README`, `docs/` или `tests/` бампа не требуют.
- **У ядра есть потолок** — `locales/<язык>/core.md` не больше 8200 символов, английское уже
  близко к нему. Всё тяжелее — в скилл.
- **Не правьте `ROADMAP.md`, `docs/roadmap/DONE.md` и `TECH_DEBT.md`.** В MAST их правит
  только основная копия, здесь это мейнтейнер при мердже. Находку или предложение —
  в issue.
- **Починка — с тестом.** Исправление бага приходит с тестом, который падал до и проходит
  после.

## Pull request

Один PR — одно изменение. Опишите, что поменяли и как проверили; CI на каждый PR гоняет
тесты, сверяет копии плагина и проверяет бамп версии.
