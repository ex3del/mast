# Участие в MAST

*English: [CONTRIBUTING.md](CONTRIBUTING.md)*

Спасибо за помощь. Баги и идеи — в [issues](https://github.com/ex3del/mast/issues), код — через
pull request в `main`. Писать можно по-русски.

## Подготовка

```bash
git clone https://github.com/<вы>/mast && cd mast
git config core.hooksPath .githooks     # pre-commit, который сторожит бамп версии
pytest                                  # весь набор должен быть зелёным
```

Живые тесты `tests/test_*_live.py` без `MAST_LIVE=1` пропускаются: они зовут настоящий `claude`
и стоят токенов.

Попробовать свои правки в Claude Code без публикации: `claude --plugin-dir plugins/ru`
(или `plugins/en`).

## Неочевидные правила

- **Тексты живут в своём плагине — `plugins/<язык>/locales/<язык>/`, код хуков — в корне,
  в `hooks/`.** Маркетплейс ставит только каталог самого плагина, поэтому в каждом лежит
  копия общих `hooks/`. Код хуков правится только в корневом `hooks/`:
  `plugins/<язык>/hooks/*.py` — сгенерированные копии, первая строка (после shebang) —
  «Сгенерировано… правь там». Копии обновляются командой `python3 tools/sync_plugins.py`;
  `--check` в pre-commit и CI не пропустит ни отставшую копию, ни копию без пометки.
- **Копии, а не символьные ссылки.** Площадка ставит каждый плагин из его каталога
  отдельно, а код нужен обоим. Git на Windows по умолчанию (`core.symlinks=false`)
  выкладывает ссылку текстовым файлом — хук падает с `SyntaxError`, ядро не вкладывается
  (проверено в A-18: 0 из 2). Не заменяйте копии ссылками.
- **Оба языка — вместе.** Правка текста в `plugins/ru/locales/ru/` требует той же правки в
  `plugins/en/locales/en/`: сторожа сверяют состав файлов и дерево заголовков. Не пишете на
  одном из языков — скажите об этом в PR, перевод доделаем.
- **Правка метода поднимает версию** в обоих `plugins/*/.claude-plugin/plugin.json` (они
  должны совпадать). Без бампа Claude Code не доставит обновление никому. Правки только
  `README`, `docs/` или `tests/` бампа не требуют.
- **У ядра есть потолок** — `plugins/<язык>/locales/<язык>/core.md` не больше 8200 символов,
  английское уже близко к нему. Всё тяжелее — в скилл.
- **Не правьте `ROADMAP.md`, `docs/roadmap/DONE.md` и `TECH_DEBT.md`.** В MAST их правит
  только основная копия, здесь это мейнтейнер при мердже. Находку или предложение —
  в issue.
- **Починка — с тестом.** Исправление бага приходит с тестом, который падал до и проходит
  после.

## Pull request

Один PR — одно изменение. Опишите, что поменяли и как проверили; CI на каждый PR гоняет
тесты, сверяет копии плагина и проверяет бамп версии.
