# Технический долг

Что оставлено криво осознанно. От пункта роадмапа отличается условием-триггером: не
«Готово когда», а **при каком условии чиним**. Закрытый долг сжимается в одну строку.

- **`/mast:init-project` не покрыт сквозным тестом.** Ограждение «`--check` не меняет ни
  одного файла» держится на трёх ручных прогонах (пункт A-1) и структурном тесте на текст
  команды (`tests/test_init_check.py`): вырезанное ограждение тест поймает, изменившееся
  поведение модели — нет. Грозит тем, что регресс сценария всплывёт у пользователя, а не у
  нас. **Чиним,** когда придёт первая жалоба, что `--check` что-то изменил, — или когда в
  наборе появится маркер для медленных тестов с живым прогоном `claude -p`. Выявлено в A-3.

- ~~Пятый артефакт каркаса живьём не создавался~~ — закрыт 22.09 ручной проверкой вне пункта: в интерактивной сессии на установленном плагине 3.1.1 `.claude/rules/example.md` создан, побайтно совпал с шаблоном. Выявлено в A-1, находки проверки — A-9.

- **Линт ругается на промежуточное состояние при закрытии пункта.** Скилл велит сначала
  писать тезис в `DONE.md`, потом удалять строку из `ROADMAP.md` — между этими двумя
  правками номер живёт в обоих файлах, и `PostToolUse` выдаёт «номер занят, пункт уже в
  DONE.md». Обратный порядок даёт другую ложную жалобу: пункты с `Зависит от` ссылаются в
  никуда. Грозит тем, что сессия, доверяющая хуку, примется «чинить» корректное закрытие.
  **Чиним,** когда жалоба собьёт закрытие пункта во второй раз (первый — A-8, 22.09):
  тогда линт должен научиться видеть пару файлов как одну правку. Выявлено в A-8.

- **Бамп версии защищён только локальным `git commit`.** `.githooks/pre-commit` не
  вызывается при `git rebase`, при мердже через веб-интерфейс GitHub и при `--no-verify`;
  `tests/test_version_bump.py` ловит пропуск, но уже после коммита. Грозит релизом, которого
  не получит ни один пользователь. **Чиним,** когда у проекта появится CI: та же проверка
  шагом workflow закрывает все обходы разом. Выявлено в A-3.
