Ты разворачиваешь в текущем проекте каркас метода MAST. Пять артефактов каркаса:
`CLAUDE.md`, `ROADMAP.md`, каталог `docs/roadmap/`, файл `.claude/rules/example.md`
(пример правила с `paths:`) и строка `.claude/worktrees/` в `.gitignore`.

Шаблоны для копирования лежат в плагине: `${CLAUDE_PLUGIN_ROOT}/locales/<язык>/templates/`
— `CLAUDE.template.md`, `ROADMAP.template.md`, `rule.template.md`.

## Шаг 0. Язык шаблонов

Язык задаёт настройка плагина `userConfig.language` (`ru` по умолчанию, `en`). Прямого доступа
к этому значению из текста команды нет — `${user_config.language}` здесь не подставляется
движком (проверено экспериментом). Определи язык косвенно — по тексту, который хук
`SessionStart` уже вложил в начало этой сессии: он читает ту же настройку и вставляет либо
ядро метода целиком, либо короткую подсказку «метод не развёрнут», на нужном языке.

- в контексте русский текст («В этом проекте метод MAST не развёрнут...» или заголовки вида
  «## Где что записывать») → язык `ru`;
- английский текст («MAST is not set up in this project...» или «## Where to write things») →
  язык `en`.

Не нашёл ни то, ни другое (хук не сработал или контекст не сохранился) — язык `ru`, это
значение по умолчанию в `plugin.json`.

## Шаг 1. Разведка

Собери и кратко покажи человеку:

- **Стек и зависимости** — по манифестам в корне проекта (`package.json`, `pyproject.toml`,
  `requirements.txt`, `go.mod`, `Cargo.toml`, `Gemfile`, ...), какие найдутся.
- **Тесты** — команда их запуска, если её видно по манифесту или CI-конфигу (`npm test`,
  `pytest`, `go test ./...`, ...). Не видно — так и скажи, не выдумывай команду.
- **Remote и ветка по умолчанию** — `git remote -v` и `git branch --show-current`. Веток в
  репозитории ещё нет (только что `git init`) — отметь это, а не выдумывай ветку.
- **Что из каркаса уже есть** — проверь каждый из пяти артефактов по отдельности: файл
  `CLAUDE.md`, файл `ROADMAP.md`, каталог `docs/roadmap/`, файл `.claude/rules/example.md`,
  и есть ли в `.gitignore` (если он существует) строка `.claude/worktrees/`.

## Шаг 2. Список и подтверждение

Покажи человеку список того, что будешь создавать — **только недостающие** из пяти артефактов.

Файл `CLAUDE.md`, `ROADMAP.md` или `.claude/rules/example.md` уже существует — не перезаписывай
его молча и не включай в список на создание. Назови его и скажи, что его правка — это режим
ревизии каркаса (отдельный сценарий для проекта с историей, в этой команде пока не реализован);
в этом прогоне он остаётся нетронутым, создаётся только то, чего не хватает.

Не хватает нечего — сообщи, что каркас уже развёрнут, и останови сценарий без вопроса.

Есть что создавать — дождись явного подтверждения человека, прежде чем писать хоть один файл.
Отказ или отсутствие ответа — ничего не создавай и на этом остановись.

## Шаг 3. Создание каркаса

После подтверждения создай только то, чего не хватало:

1. `CLAUDE.md` — копия `${CLAUDE_PLUGIN_ROOT}/locales/<язык>/templates/CLAUDE.template.md`.
2. `ROADMAP.md` — копия `${CLAUDE_PLUGIN_ROOT}/locales/<язык>/templates/ROADMAP.template.md`.
3. `docs/roadmap/` — пустой каталог. Git не хранит пустые каталоги — это нормально, он
   появится в дереве вместе с первым пунктом роадмапа.
4. `.claude/rules/example.md` — копия `${CLAUDE_PLUGIN_ROOT}/locales/<язык>/templates/rule.template.md`.
5. Строка `.claude/worktrees/` в `.gitignore`: файла нет — создай его с этой строкой; файл
   есть, строки нет — допиши в конец; строка уже есть — файл не трогай.

Плейсхолдеры вида `<...>` внутри скопированных шаблонов не заполняй сам — их вписывает
человек под свой проект.

## Шаг 4. Линт и что дальше

`ROADMAP.md` в проекте теперь есть (создан сейчас или уже был) — прогони:

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/hooks/roadmap_lint.py ROADMAP.md
```

Код не ноль — покажи нарушения как есть, сам не чини: шаблон обязан проходить линт, так что
непройденный линт значит либо чужой `ROADMAP.md` (уже существовал до этой команды), либо
испорченный шаблон — оба случая решает человек, не тихая правка.

Код ноль — скажи, что каркас развёрнут, и что сделать дальше:

- открыть `CLAUDE.md` и `ROADMAP.md`, заменить плейсхолдеры данными проекта;
- завести первый реальный пункт роадмапа скиллом `managing-roadmap-items` (для русского
  языка — `managing-roadmap-items-ru`);
- закоммитить каркас.
