# Модели и чувствительные зоны

Зоны, которые всегда ведёт `opus`, по строке на зону — путь и чем грозит ошибка:

- `<путь/**>` — только opus: <почему здесь нельзя ошибиться>

**Пока этого файла нет, всё идёт на `opus`.** Он существует ровно затем, чтобы разрешить
`sonnet` там, где это безопасно: ошибка обнаружима сверкой с существующим, откатывается
одним `git revert` и бьёт по одному пункту. Три условия — в скилле ведения пунктов.

Советник: у `opus` — `fable`, у `sonnet` — `opus`. Советника `fable` сессии на `sonnet`
не давать: субагенты наследуют советника сессии, Fable размножится по ним и выйдет дороже,
чем сразу `opus`.

Пути в `paths:` — те же чувствительные зоны: тогда правило само приедет в контекст, когда
агент до них доберётся. Диспетчер читает этот файл по имени, перед запуском сессии.
