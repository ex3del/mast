# MAST

Method for Agents, Sessions and Tasks — плагин Claude Code, который разворачивает в чужом
проекте наш способ работы: роадмап с пунктами, worktree на пункт, диспетчер, правила с `paths:`,
архив закрытого.

## Куда смотреть

| Документ | Когда читать |
|---|---|
| [ROADMAP.md](ROADMAP.md) | что осталось сделать |
| [docs/roadmap/A-1/SPEC.md](docs/roadmap/A-1/SPEC.md) | зачем плагин так устроен, ограничения площадки, состав ядра |

## Стек

- Markdown — тексты ядра, скиллов, команд и шаблонов, по комплекту на язык в `locales/`.
- Python 3 (только stdlib) — скрипты хуков и сторожа́.
- pytest — сторожа́ в `tests/`.

## Команды

```bash
pytest                                    # весь набор
python3 hooks/roadmap_lint.py ROADMAP.md  # проверка формата роадмапа
python3 hooks/roadmap_lint.py --ready ROADMAP.md
```

## Инварианты проекта

- **Плагин не трогает чужое.** Ни `~/.claude/CLAUDE.md`, ни `settings.json` пользователя, ни файлы его проекта без подтверждения. Любая правка существующего файла — только через дифф и вопрос.
- **Ядро в `SessionStart` ≤ 6000 символов** при лимите площадки 10 000. Не влезает — значит секция уезжает в скилл, а не сокращается до непонятности.
- **Два языка равноправны.** Правка текста на одном языке без правки на другом не вливается: сторож локалей сверяет состав файлов и дерево заголовков.
- **Пути внутри плагина — через `${CLAUDE_PLUGIN_ROOT}`.** Никаких `$HOME/.claude/...`: у пользователя плагина такого пути нет.
- **Числа в «Готово когда» получены замером**, а не переписаны из примера.
