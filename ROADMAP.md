- **A-14** `mast merge`: вливание одной командой и rebase очереди готовых веток — запланирован · —

- **A-15** Ревью с чистым контекстом перед вливанием — запланирован · —
  Зависит от: A-14
  Правки `.claude/rules/` сессия пункта вносит при закрытии, а при вливании их сейчас никто не смотрит: диспетчер сверяет только замеры. Решение человека — иерархия: ревьюер с чистым контекстом критически оценивает дифф, человек — только когда ревьюер не уверен. `mast merge` сам вызывает ревьюера (`claude -p`, фиксированный промпт, на входе только дифф и «Готово когда», без истории пункта), ответ JSON: `ок` / `отказ` с причинами / `не уверен`. `отказ` — ветка возвращается сессии, `не уверен` — пункту слот `ждёт человека`. Ветка трогает `.claude/rules/`, `CLAUDE.md`, скиллы — планка строже, любое сомнение к человеку. Вызов ревью — скриптом, а не прозой: пропустить его нельзя.
  Мои пути: hooks/**, plugins/*/**, locales/*/skills/**, tests/**
  Готово когда: на фикстурах, по 3 прогона: заведомо плохая правка rules — не `ок` 3 из 3; чистая правка — `ок` 3 из 3; правка кода, нарушающая «Готово когда», — `отказ` 3 из 3; `mast merge` без вердикта не вливает — 1 из 1; цена одного ревью в токенах — замерена и записана в коммит.
