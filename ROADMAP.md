- **A-15** Ревью с чистым контекстом перед вливанием — запланирован · —
  Зависит от: A-14
  Правки `.claude/rules/` сессия пункта вносит при закрытии, а при вливании их сейчас никто не смотрит: диспетчер сверяет только замеры. Решение человека — иерархия: ревьюер с чистым контекстом критически оценивает дифф, человек — только когда ревьюер не уверен. `mast merge` сам вызывает ревьюера (`claude -p`, фиксированный промпт, на входе только дифф и «Готово когда», без истории пункта), ответ JSON: `ок` / `отказ` с причинами / `не уверен`. `отказ` — ветка возвращается сессии, `не уверен` — пункту слот `ждёт человека`. Ветка трогает `.claude/rules/`, `CLAUDE.md`, скиллы — планка строже, любое сомнение к человеку. Вызов ревью — скриптом, а не прозой: пропустить его нельзя.
  Мои пути: hooks/**, plugins/*/**, tests/**
  Готово когда: на фикстурах, по 3 прогона: заведомо плохая правка rules — не `ок` 3 из 3; чистая правка — `ок` 3 из 3; правка кода, нарушающая «Готово когда», — `отказ` 3 из 3; `mast merge` без вердикта не вливает — 1 из 1; цена одного ревью в токенах — замерена и записана в коммит.

- **A-17** Справка после `/compact`: роль сессии и строка её пункта — запланирован · —
  Зависит от: A-16
  После сжатия контекста хук `SessionStart` (`compact`) возвращает только ядро; в каком пункте сессия, её критерий и где план — модель вспоминает сама. Соблюдение правил падает на 5,6% шансов с каждой следующей функцией ([arXiv 2605.10039](https://arxiv.org/abs/2605.10039)). Как `gt prime` в Gas Town: хук добавляет к ядру справку — сессии в `.claude/worktrees/X-N` её строку из `ROADMAP.md` основной копии и путь к `STATUS.md`, диспетчеру — вывод `mast status`.
  Мои пути: hooks/**, plugins/*/**, tests/**
  Готово когда: после `/compact` на установленном плагине в контексте сессии пункта — номер, «Готово когда» дословно и путь к `STATUS.md` 1 из 1; у диспетчера — вывод `mast status` 1 из 1; в сессии вне worktree и без роли справки нет — 0 из 1; справка ≤ 1500 символов (ядро en 8147 при лимите площадки 10 000).

- **A-19** `mast start`: запуск пункта одной командой — 🔨 в работе · `worktree-A-19` · сессия `A-19` · с 24.09
  Зависит от: A-14
  Запуск — проза на 1761 символ (ru), модель проходит пять шагов по памяти: готовность и пересечение `Мои пути`, выбор модели, пометка строки и коммит, `claude --bg` с промптом, команда `claude attach <id>` человеку (`attach` принимает только id, проверено 23.09). В `reinhold-dispatch` промпт старта — медиана 1165 символов при образце ~220, с проектными указаниями; один запуск диспетчер написал ad hoc Python-вставкой на 3,4k символов. `mast start X-N` на CLI из A-14 делает всё это и печатает последней строкой `claude attach <id>`; push — только если его разрешил человек, иначе база worktree `"worktree": {"baseRef": "head"}`. Решение человека: нужен, но вторым после `mast merge` — ошибка запуска дешёвая и видна сразу, ошибка вливания дорогая. Ресёрч: [контракты](docs/research/2026-09-23-deterministic-contracts.md).
  Мои пути: hooks/**, plugins/*/**, tests/**, README.md, README.ru.md, CLAUDE.md
  Готово когда: на фикстуре отказы на неготовый пункт, пересечение путей без `--force "причина"`, `sonnet` на opus-зоне, `fable` у `sonnet` — 4 из 4; свободный хвост промпта старта ≤ 300 символов; последняя строка вывода — `claude attach <id>` с id, совпадающим с `claude agents`, 1 из 1; на установленном плагине — 1 из 1; раздел «Запуск пункта» ru ≤ 400 символов (сейчас 1761).
